# spinner
Colored balls playfully swapping positions placed equally on a circle.

**Live:** https://sannyer.github.io/spinner/

- `index.html` – general N-gon spinner (N = 3–20 vertices, K = skipped elements, adjustable overlap, swap order direction, top/bottom layering rules incl. per-ball balance).
- `pentagon_symmetry_3d_spinner.html` – the original fixed pentagon version (5 vertices, 30-step loop).

Pure static HTML, no build step. Tailwind and Google Fonts load from CDN.
